# Enrich Contributor Candidates with a consented Public Profile summary

Refining ADR 0010, Core enriches an authenticated Contributor Candidate with an optional Public Profile summary containing its public identifier, Entry Year, and whether a ready profile photo exists. Core returns that summary only while the Person has active Profile Consent; otherwise the candidate contains only the locked Roster first and last names plus its short-lived opaque reference. Student ID, Account ID, and Person ID remain excluded. The Student authoring surface renders the summary as optional identification context, uses a generic fallback avatar when it is absent or its image fails, and locks a selected candidate into a removable card with the contribution-role field.

We rejected returning Student ID or a masked Student ID because even partial roster identifiers increase enumeration and correlation risk and contradict the private authentication-data boundary. We also rejected returning profile photo and Entry Year without Profile Consent because they are Public Profile data, not Contributor attribution requirements. The accepted cost is that candidates without active consent have less distinguishing context and that withdrawing consent removes their enrichment while leaving the locked Roster name available for the existing Account-backed Contributor flow.
