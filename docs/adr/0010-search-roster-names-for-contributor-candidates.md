# Search Roster names for Contributor Candidates

Core allows an authenticated Submitter editing an owned Work Draft to search existing Student and Alumnus People by partial Roster first name, last name, full name, or one exact eight-digit Student ID. Results are rate-limited, indexed, capped at eight, and contain only locked Roster first and last names plus a short-lived opaque candidate reference; Student ID remains request-body-only and never enters a response, URL, log, metric, cache, Work, Contributor, Revision, Notification, audit payload, or client persistence. Selecting a candidate creates an Account-backed Contributor, while submitting an entered full name without a selected candidate creates a distinct External Contributor and never links by name. This supersedes ADR 0006's exact-ID-only lookup boundary. We rejected retaining exact-ID-only lookup because the chosen authoring experience requires discoverable name suggestions, accepting increased authenticated Roster enumeration and disclosure risk while retaining ownership checks, mutation authorization, bounded results, rate limits, and opaque references.

Superseded by ADR 0013 for Student ID prefix search.
